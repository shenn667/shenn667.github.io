cited-rag — Evaluation

Software Quality Engineering report · v0.1.0 · QA certified 2026-11-16 (board cited-rag, task t_e42b7406) · Scope: PRODUCT_BRIEF.md §2 · Verdict: PASS 6/6

Local RAG you can trust. Zero hallucination by design: every claim is cited ([file:L1-L2]) or the answer is refused with Insufficient evidence. Stdlib-only, offline-first.

1. Reproducible protocol

One command reproduces every number below from the bundled golden set — run it, don't trust this table:

pip install cited-rag
cited-rag index ./docs --db ./index.db
cited-rag eval --golden eval/golden.jsonl
  • Corpus: 12 docs (examples/docs/) — BM25/RFF tuning notes, chunking, CLI, fidelity, refusal, eval-metrics, LLM adapter, security, offline-portfolio.
  • Golden set: eval/golden.jsonl, n = 52 questions — 40 in-corpus (should_refuse: false, each mapped to an expected_doc) + 12 out-of-corpus (should_refuse: true: sport, cuisine, médecine, histoire…).
  • Environment: Python 3.12, zero dependencies (dependencies = []), pure offline (no socket/urllib outside the opt-in adapter).
  • Generation contract: extractive verbatim + exact [file:Lstart-Lend] offsets; refusal trigger max_score < --min-score (default 0.35) or fidelity < 0.5; refused answers carry zero citations, exit 0.

4. Honest limitations

  • Small corpus: ~12 demo docs — rare-term IDF statistics are noisy; scores stabilize as the corpus grows. Re-index after every corpus change.
  • Lexical retrieval only by default: BM25 + TF-IDF miss paraphrases and cross-lingual queries. The dense adapter (--llm) is opt-in and unevaluated against the gates above.
  • Extractive answers: verbatim quoting is faithful but stilted — no synthesis, no multi-hop reasoning, fixed fidelity threshold (0.5).
  • Secrets: the indexer warns on key-like patterns (AKIA…, ghp_…) but does not redact — scrub corpora before indexing.
  • Scale: single-machine SQLite/JSON index; not a distributed search engine and makes no such claim. The 50-doc budget was not measured at exactly 50 docs.
